# test-vite
* Vue3 + Ts + Vite
* scss
* eslint + prettier

# 指令列表
### 啟動專案
```bash
npm run dev
```
### 建構專案
```bash
npm run build
```
### 建構專案後,本地測試應用
```bash
npm run preview
```

# 快速連結
線上展示: https://pokemon085.github.io/test-vite/


# 資料夾架構
```text
├── public 靜態資源
└── src
    ├── api API接口
    ├── assets 靜態資源
    ├── components 共用元件
    ├── pages 主要頁面
    ├── router 路由
    ├── utils 工具函數
    └── store pinia 狀態模組
```

# 技術
1. 框架: Vue 3 (Composition API)
2. 構建工具: Vite
3. 狀態管理: Pinia
4. 路由管理: Vue Router
5. 樣式處理: SCSS
6. 網路請求: Axios
